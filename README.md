
# Tafelapp

## Beschrijving
Dit is een eenvoudige webapplicatie waarmee je de tafels van vermenigvuldiging kunt oefenen.

De gebruiker kan een tafelnummer invoeren en vervolgens op de knop 'Laat tafel zien' klikken.

De applicatie toont daarna automatisch de gekozen tafel van 1 tot en met 10.

## Gebruikte technieken
- HTML
- CSS
- Bootstrap 5
- JavaScript

## Functionaliteiten
- Een tafelnummer invoeren.
- Controleren of het tafelnummer tussen 1 en 10 ligt.
- De gekozen tafel automatisch weergeven.
- Gebruiksvriendelijke interface met Bootstrap.

## Installatie en gebruik
1. Download of clone deze repository.
2. Open de projectmap.
3. Open het bestand `index.html` in je browser.
4. Vul een tafelnummer in.
5. Klik op 'Laat tafel zien'.
